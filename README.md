# Ideas gRPC service

Готовый Go-сервис без HTTP-транспорта: внешний API доступен только по gRPC.

## Что есть

- Контракт в `proto/ideas/v1/ideas.proto`: CRUD-методы `IdeaService`.
- Реализация с потокобезопасным in-memory хранилищем и корректными кодами gRPC.
- Стандартный gRPC health service.
- Демонстрационный клиент и unit-тесты.

## Запуск

В первом терминале:

```sh
go run ./cmd/server
```

Во втором:

```sh
go run ./cmd/client
```

Адрес сервера меняется переменной `GRPC_ADDR` (по умолчанию `:50051`). Для рабочего окружения вместо небезопасного соединения клиента необходимо подключить TLS.

## Проверка и регенерация кода

```sh
go test ./...
make generate
```

Для регенерации требуются `protoc`, `protoc-gen-go` и `protoc-gen-go-grpc`; генераторы уже установлены в стандартном Go bin-каталоге пользователя.
